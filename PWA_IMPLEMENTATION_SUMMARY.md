## 🔒 Security & Performance

### HTTPS Required
- Service workers only work on HTTPS (or localhost)
- Vercel/Netlify automatically provide HTTPS
- Development works on http://localhost

### Caching Strategy
- **Static assets**: Precached at install time
- **API calls**: Network-first with 10s timeout, cached fallback
- **Images**: Cache-first with 30-day expiration
- **Fonts**: Cache-first with 1-year expiration

### Update Strategy
- Checks for updates every hour
- Activates immediately with `skipWaiting`
- Prompts user to reload for updates
- Old caches cleaned automatically

## 🐛 Troubleshooting

### Service Worker Not Registering
```javascript
// Check in browser console
navigator.serviceWorker.getRegistrations().then(registrations => {
  console.log('Registered:', registrations.length);
});
```

### Clear Everything and Start Fresh
```javascript
// Run in browser console
navigator.serviceWorker.getRegistrations().then(registrations => {
  registrations.forEach(r => r.unregister());
});
caches.keys().then(keys => keys.forEach(k => caches.delete(k)));
location.reload();
```

### Update Not Showing
- Hard refresh: Cmd+Shift+R (Mac) / Ctrl+Shift+R (Windows)
- Clear browser cache
- Unregister service worker manually
